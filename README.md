# SaaS-Frontend

React + Vite + TypeScript frontend for the SaaS platform.

## Setup

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server (port 5173) |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |

API requests are proxied to the backend at `http://localhost:5000` during development.
